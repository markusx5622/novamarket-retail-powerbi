# LEEME de entrega

## Propósito

Este documento resume los entregables principales del proyecto **NovaMarket Retail** y facilita una revisión rápida de la entrega académica.

## Estado general

- **Estado del dashboard:** versión `v0.9` disponible para revisión del profesor.
- **Archivo principal Power BI:** `powerbi/NovaMarket_Retail_Dashboard_v0.9_revision_profesor.pbix`
- **Repositorio de trabajo:** este repositorio GitHub concentra datos, scripts, documentación y evidencias visuales.

## Entregables principales

### 1. Dashboard Power BI

- Archivo: `powerbi/NovaMarket_Retail_Dashboard_v0.9_revision_profesor.pbix`
- Estado: versión candidata para revisión académica.

### 2. Datos

- Dataset original: `data/raw/Base_Datos_Proyecto_Final_NovaMarket_Retail.csv`
- Dataset limpio: `data/processed/novamarket_retail_limpio.csv`

### 4. Memoria y documentación

### 6. Presentación y guion

## Material complementario

- Landing page documentada en `docs/landing_page.md`

## Nota de revisión

La entrega está organizada para que el profesor pueda localizar de forma rápida el archivo PBIX, los datos de soporte, la memoria, las capturas y el guion de defensa. La documentación complementaria añadida refuerza la trazabilidad, la validación y el uso del dashboard sin modificar los artefactos analíticos originales.
