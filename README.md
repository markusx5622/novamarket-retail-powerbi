# NovaMarket Retail – Power BI Dashboard

## Descripción del proyecto
Este repositorio académico corresponde al proyecto final de la asignatura **Proyecto: Análisis de Datos** del Grado en Ingeniería (Equipo 9). El objetivo es diseñar un **dashboard ejecutivo en Microsoft Power BI** para el caso empresarial ficticio **NovaMarket Retail**.

## Contexto empresarial
NovaMarket Retail es una empresa omnicanal especializada en productos de **Tecnología** y **Estilo de Vida**, con operaciones en:
- España
- México
- Argentina
- Chile
- Colombia

El análisis se centra en el año **2025**, considerando rendimiento comercial, categorías de producto, desempeño por país/canal, satisfacción del cliente y logística.

## Objetivo del repositorio
Proveer una estructura profesional, limpia y trazable para:
- Documentar la memoria académica del proyecto.
- Organizar datos crudos y procesados.
- Centralizar scripts de validación y limpieza.
- Gestionar medidas DAX y tema visual de Power BI.
- Preparar materiales de presentación y defensa final.

## Herramientas principales
- **Microsoft Power BI Desktop** (modelado y visualización)
- **Python** (validación/limpieza de datos y exportes de apoyo)
- **Git/GitHub** (control de versiones y entrega académica)

## Alcance y limitaciones
- Este repositorio **no incluye datos inventados** ni simulaciones.
- El dataset real (CSV) debe ubicarse en `data/raw/`.
- El archivo final `NovaMarket_Retail_Dashboard.pbix` se incorporará cuando el equipo complete el desarrollo en Power BI.
- Los scripts de `scripts/` se documentan como plan de trabajo y se añadirán con implementación real en fases posteriores.
