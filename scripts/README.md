# scripts

Esta carpeta contendrá los scripts Python del flujo de preparación analítica.

## Archivos planificados
- `01_validacion_dataset.py`: verificación de integridad, tipos de datos, nulos y duplicados.
- `02_limpieza_dataset.py`: estandarización, limpieza y generación del dataset procesado.
- `03_export_resumen_kpis.py`: exportación de resúmenes/KPIs de apoyo para contraste documental.

## Estado actual
Los scripts aún no se incluyen porque se incorporarán con lógica real y trazable en la siguiente fase del proyecto.
