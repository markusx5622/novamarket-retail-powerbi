# Diccionario de Datos

| Campo | Tipo sugerido | Descripción |
|---|---|---|
| ID_Pedido | Texto | Identificador único del pedido. |
| Fecha | Fecha | Fecha de registro de la transacción. |
| ID_Cliente | Texto | Identificador único del cliente. |
| Pais | Texto | País de la operación (España, México, Argentina, Chile, Colombia). |
| Categoria | Texto | Categoría de producto (Tecnología o Estilo de Vida). |
| Producto | Texto | Nombre del producto comercializado. |
| Precio_Unitario | Decimal | Precio unitario del producto. |
| Cantidad | Entero | Unidades vendidas en la transacción. |
| Costo_Envio | Decimal | Costo logístico asociado al pedido. |
| Canal_Venta | Texto | Canal de venta utilizado. |
| Puntuacion_Satisfaccion | Entero/Decimal | Valor de satisfacción reportado por cliente. |
