# Metodología de Trabajo

## Enfoque analítico
El proyecto sigue un enfoque **descriptivo-exploratorio** para interpretar el desempeño de NovaMarket Retail durante 2025, transformando datos transaccionales en indicadores ejecutivos.

## Etapas metodológicas

### 1) Validación del dataset
- Revisión de estructura y tipos de datos.
- Detección de nulos, duplicados e inconsistencias.
- Verificación de campos clave para modelado analítico.

### 2) Limpieza y preparación
- Estandarización de nombres/categorías.
- Normalización de formatos.
- Generación del dataset procesado para consumo en Power BI.

### 3) Modelo semántico
- Definición de tablas y relaciones necesarias.
- Construcción de una capa semántica clara para el cálculo de KPIs.
- Organización de medidas para facilitar mantenimiento y trazabilidad.

### 4) Cálculo de KPIs con DAX
- Implementación de medidas base (ingresos, pedidos, clientes, unidades, envío).
- Construcción de indicadores derivados (ticket medio, satisfacción alta, porcentaje de ingresos).
- Validación cruzada de coherencia entre medidas.

### 5) Diseño visual del dashboard
- Estructura en cuatro páginas con narrativa ejecutiva.
- Uso de tema visual corporativo para consistencia gráfica.
- Priorización de legibilidad, jerarquía visual y comparabilidad.
