# Presentación de validación inicial

Esta carpeta contiene la presentación usada por **Marc Cubero Cantavella** para defender y validar la propuesta de NovaMarket Retail.

El documento incluye contexto empresarial, problema de negocio, público objetivo, relación con ODS, justificación del dataset y conclusiones iniciales.

Esta presentación no sustituye al dashboard final ni a la memoria académica, sino que documenta la fase inicial de validación de la propuesta.
